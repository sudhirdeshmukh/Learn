# Design Patterns Documentation Site

Interactive documentation site built with React, Vite, and Tailwind CSS.

## 🚀 Quick Start

```bash
npm install
npm run dev      # Development server at http://localhost:5173
npm run build    # Production build
npm run deploy   # Deploy to GitHub Pages
```

## 📁 Structure

- `src/components/` - Layout and reusable components
- `src/pages/` - Route pages (Home, patterns, system design, etc.)
- `src/data/` - Pattern content and code examples

## 🎯 Features

- 7 Design Patterns with detailed explanations
- System Design FAQs  
- Interview Q&A
- Quick Revision cards
- Responsive Tailwind CSS design

## 🌐 Deployment

Update `package.json` homepage and `vite.config.js` base for your repository, then:
```bash
npm run deploy
```

Built for learning design patterns with Spring Boot.
